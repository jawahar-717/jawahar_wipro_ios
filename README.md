# Swift Exercises - Topics 2 to 12

Solutions for the iOS / Swift Training Exercises (Karpagam College of Engineering).
One Swift file per topic, with all three tasks of that topic inside it.

Run a file in an Xcode Playground, or from a terminal: `swift Topic02_Variables_and_Constants.swift`

Lines that are meant to fail (compile errors) are commented out and explained next to the line.
